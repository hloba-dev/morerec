# Генератор реквизитов (React)

Одностраничное приложение на Next.js: формирует платёжные реквизиты (4 платежа,
карта / телефон / СБП, выбор банка, RU/EN) и копирует готовый текст в буфер.
После копирования форма очищается. Заточено под iPhone Safari. Очистка формы —
через модальное окно. База данных не используется — всё работает на клиенте.

## Локальный запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Деплой на Vercel

1. Залить репозиторий на GitHub.
2. На vercel.com → **Add New → Project** → импортировать репозиторий.
3. Deploy. Vercel сам определит Next.js — никаких переменных окружения не нужно.

## Что и где

- `app/page.tsx` — страница, рендерит форму.
- `components/PaymentForm.tsx` — вся логика формы (порт из PHP-плагина).
- `components/Modal.tsx` — модальное окно подтверждения очистки.
- `lib/generate.ts` — генерация текста реквизитов (формат 1:1 с оригиналом).
- `lib/i18n.ts`, `lib/banks.ts` — локализация и банки.
